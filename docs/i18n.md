# Language (RO / EN)

The whole interface can be switched between Romanian and English from **Settings → App language**
(or from the RO / EN pill on the login and register pages). The change applies instantly.

## How it works

- `i18n/i18n.service.ts` holds the current language in a signal and remembers it in `localStorage`.
- The Romanian text is the translation key: templates use `{{ 'Tranzactii' | t }}`, code uses `i18n.t('...')`.
- `i18n/en.ts` maps every Romanian text to English. A missing entry simply falls back to Romanian.
- Placeholders: `i18n.t('Bine ai venit, {name}!', { name })`.
- Numbers and dates use `ro-RO` or `en-US` formatting depending on the language.
- The same setting is saved on the server (`UserSettings.Language`), so Ax (the advisor) and quick add
  answer and parse in the chosen language.

## Adding a new text

1. Write it in Romanian in the template with `| t` (or `i18n.t()` in TypeScript).
2. Add the English translation to `i18n/en.ts` with the exact same Romanian key.
